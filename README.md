## Como importar projetos respeitando a autoria

1. Abra o repositório original e verifique o arquivo **LICENSE** e os avisos de copyright.
2. Quando permitido, prefira o recurso **Fork** do GitHub, que mantém a referência ao repositório de origem.
3. Para cópias ou modificações, mantenha os arquivos de licença, atribuições e avisos exigidos.
4. Se não houver licença explícita, **não copie nem redistribua o código** sem autorização.
5. Não importe tokens, credenciais, dados de clientes nem código de repositórios privados.
6. Registre em [IMPORTACOES.md](IMPORTACOES.md) as verificações antes de importar.

## Contribuições

Sugestões e correções podem ser propostas por issues ou pull requests. Ao sugerir um projeto, inclua o link original, o autor, a finalidade e a licença identificada.
